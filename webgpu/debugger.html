About

Time-travel debugger for Continuous Thought Machines. Step through 16 thinking ticks on a d=5 surface code QEC decoder (278K params, ONNX inference in browser).

Forward correction — At each tick, compute optimal NLM weights via Cholesky least-squares on trace history. Nudge activations toward optimal by α. Based on Angeris (2022) SDP bound framework. The Cholesky solver runs inside the ONNX graph — no external computation.

Hebbian plasticity — CTM sync signal (pairwise neuron products) is a natural substrate for Hebbian learning. The forward correction is a principled formulation where the SDP bound provides the optimization target. Open problem: finding a regulation mechanism where correction consistently improves accuracy. The α slider lets you explore this.

Controls: New Syndrome → generate + infer. Arrow keys or ▶ to step ticks. α slider for correction strength. Run 100 compares base (α=0) vs corrected.
